# Nassau Candy Profitability & Margin Analysis Dashboard

This project analyzes product profitability and margin performance for Nassau Candy Distributor using data analytics and machine learning techniques.

The goal of this project is to identify profitable products, detect low-margin products, analyze division-wise performance, and provide business insights through an interactive Streamlit dashboard.

---

# Project Overview

Many products generate high sales but low profit because of high operational or manufacturing costs. This project helps understand:

- Which products generate the highest profit
- Which products have low margins
- Which divisions perform better
- Which products create business risk
- How profit is distributed across products

The dashboard provides a complete business analytics solution with interactive visualizations and predictive analysis.
